## 📌 Featured Projects

### 🧻 SOFT TISSUE — Customer Ordering & Business Management Demo

A Flutter-based B2B tissue-product ordering and business workflow prototype developed as a client/investor demonstration.

**Customer workflow:**
`Home → Products → Product Details → Cart → Customer Details → Submit Order → Order Confirmation`

**Business workflow:**
`Business Dashboard → Order Details → Order Management → Production/Order Status`

**Order lifecycle:**
`New → Confirmed → Processing → Dispatched → Delivered`

**Key features:**
- Product catalogue with product images
- Carton-based ordering
- Customer/company details
- Mobile number, GST and delivery address capture
- Automatic order ID generation
- Order details for the business team
- Business dashboard with order status
- Production/order progress management
- Release Android APK demonstration build

**Technology:** Flutter, Dart, Android, Material UI

**Project status:** ✅ Client Demo V1 completed and release APK built
