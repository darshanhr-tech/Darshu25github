## Current implementation described
- Raspberry Pi 5 (8 GB RAM), Debian 13, Python 3.13
- Zebronics USB webcam
- OpenCV with LBPH face recognition
- TensorFlow Lite EfficientDet Lite0 object detection
- Flask-based browser dashboards
- Arduino Uno connected through serial communication for motor-control operations
- Separate Google Gemini integration running on an Intel MacBook Pro; exact communication protocol requires verification

## Dashboard interfaces
1. Face tracking and training
2. Motor control
3. BUJJI AI output
4. Combined face tracking and output

## Important scope note
Voice interaction, fall detection, navigation, obstacle avoidance, multilingual interaction and advanced humanoid mobility are future development goals unless later source code and testing establish otherwise. Performance metrics have not yet been supplied.
