BUJJI AI

Intelligent Human-Interactive Robot

INEX EXPO • Innovation Project

An expandable robotics platform bringing together computer vision, face recognition, object detection, AI-generated responses and basic robotic control.

Project overview

BUJJI AI is a human-interactive robot development project. The current Raspberry Pi implementation combines camera-based visual processing, registered-face recognition, object detection, browser dashboards and a microcontroller interface for motor-control operations. A separate Google Gemini integration runs on an Intel MacBook Pro; its responses are reported to be communicated to the Raspberry Pi system. The exact communication protocol is still to be documented.

Current system architecture

Primary computer

Raspberry Pi 5 — 8 GB RAM
Debian 13 • Python 3.13

Runs the main vision and Flask dashboard functions.

Visual input

Zebronics USB webcam

Provides live camera input for face recognition and object detection.

Face recognition

OpenCV + LBPH

Uses trained face data. Current development setup includes two test identities.

Object detection

TensorFlow Lite EfficientDet Lite0

Analyses camera input for objects supported by the model.

AI integration

Google Gemini

Runs separately on an Intel MacBook Pro. The Pi communication path requires source-code verification.

Hardware control

Arduino Uno

Connected to the Raspberry Pi through serial communication for motor-control operations.

Potential applications

Human–robot interaction

Explore interactive experiences between people and intelligent robotic systems.

Elderly assistance research

Potential future use for reminders, companion interaction and caregiver alerts. These features require implementation and validation.

Education and research

A modular platform for learning robotics, computer vision and AI integration.

Innovation focus

  • Combines face recognition and object detection in one camera-based robotic platform.
  • Organises functions through multiple browser-based dashboards.
  • Connects Raspberry Pi processing with Arduino motor-control operations.
  • Explores a distributed AI architecture using a separate Gemini-enabled computer.

Future development

Planned areas include direct voice interaction, multilingual communication, improved perception, additional sensors, fall-detection research, navigation and obstacle avoidance, and more advanced humanoid movement. These are future development goals, not claims of completed functionality.
